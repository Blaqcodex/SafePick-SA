# features/driver/

The driver's experience. Mobile-first, one-handed, safety-critical.

- Today's roster (`GET /api/custody/roster/{driverId}?date=`)
- Confirm pickup (`POST /api/custody/confirm-pickup`)
- Mark not-in-car (`POST /api/custody/mark-not-in-car`)
- Batch confirm (`POST /api/custody/batch-confirm`)

Motion restraint: zero animation on the critical path.
Big tap targets. Minimal chrome. Works with gloves, sun, one hand.
