# Glossary

| Term | Meaning |
| --- | --- |
| Assignment | A time-bounded association between a learner and transport provider. |
| Custody | Responsibility for a learner during a transport handover. |
| Custody event | An attributable record of an observed custody action. |
| Custody expectation | A pickup inferred from an active assignment and transport window. |
| Custody gap | An expected handover that has no resolving event after its grace period. |
| Driver approval | A school's decision that a registered driver may provide transport. |
| Invitation | A time-bounded, single-use grant used to create an invited account. |
| Operator | The seeded root account that invites school administrators. |
| Parent contact | A learner's contact record; it is not a user account. |
| Reconciliation | Comparing expected pickups with recorded events to identify gaps. |
| School | The tenant and operational authority for its own learner transport. |
| Transport window | The period in which a learner handover is expected. |
